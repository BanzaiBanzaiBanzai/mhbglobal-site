# MHB Global Sweden website

Local review implementation on branch `preview/company-website`. No push or deployment.

Run `node preview.mjs` and open http://127.0.0.1:5194. Node 24 is sufficient; no packages required. The server exposes only the website files, not repository metadata or project documentation.

Swedish default, English switch, responsive menu, three interactive design examples, quote validation and a local request review dialog. The form does not transmit or persist requests. Before launch connect a managed submission service, confirm support@mhbglobal.se delivery, configure spam protection, finish privacy information, and remove preview notices/noindex only after approval. Deploy only index.html, privacy.html, styles.css, app.js and assets/.

Media: approved photo copies; private records remain outside this public repository in the shared Media Library. Nothing in docs/ is private media provenance. See docs/PROJECT_PLAN.md for acceptance evidence and remaining work.
